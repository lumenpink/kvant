Kvant (kv)

Micro-editor de texto para terminal desenvolvido em Rust puro. Zero dependências externas, inicialização instantânea e navegação universal por teclado.

Repositório no Codeberg Guia de Atalhos
kvant — terminal session
# Documento de Trabalho — Gosplan
Este editor foi projetado para edição rápida e direta.
Você pode navegar com as setas ou via combinações Ctrl+ clássicas.

- Zero crates externas (Apenas Rust Std + POSIX termios).
- Binário autocontido com menos de 1 MB.
- Integração de primeira classe com o CCCP Divã.

⚡ Zero Dependências

Construído sem crates externas pesadas. Compilação ultrarrápida direto com a biblioteca padrão do Rust e syscalls POSIX nativas.

⌨️ Navegação Universal

Suporta setas do teclado e atalhos completos estilo Readline/Emacs (Ctrl+P, Ctrl+N, Ctrl+B, Ctrl+F, Ctrl+A, Ctrl+E) para quem não tem setas funcionais.

🛡️ Autocontido & Estático

Gera um binário único que pode ser copiado e executado em qualquer ambiente Linux/POSIX sem dependências dinâmicas no sistema operacional.

Tabela de Atalhos de Teclado

Atalho Ação Equivalente
Setas ou ^P / ^N Mover Vertical Linha Anterior (Cima) / Próxima Linha (Baixo)
Setas ou ^B / ^F Mover Horizontal Caractere Anterior (Esquerda) / Próximo (Direita)
Home ou ^A Início da Linha Pula para o primeiro caractere da linha atual
End ou ^E Fim da Linha Pula para o final da linha atual
PageUp / PageDn Rolar Página Rola uma tela inteira para cima ou para baixo
^K Cortar Linha Apaga do cursor até o final da linha
^U Limpar Linha Remove toda a linha atual
^D ou Delete Deletar Frente Apaga o caractere à frente do cursor
Backspace ou ^H Deletar Trás Apaga o caractere anterior ao cursor
^S Gravar Arquivo Salva o buffer no disco
^X ou ^Q Sair Encerra o editor (solicita confirmação se alterado)

Instalação Rápida

# Clonar e compilar via Cargo:
git clone ssh://git@codeberg.org/lumenpink/kvant.git
cd kvant
cargo build --release
cp target/release/kv ~/.local/bin/kv
cp target/release/kvant ~/.local/bin/kvant
